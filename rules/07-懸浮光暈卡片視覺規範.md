# 懸浮光暈卡片視覺規範（Floating Glow Card）

> 這是「剪接台」使用者確認喜歡、當成固定視覺風格延用的規範。圖片/Logo類疊加素材套用本規則，跟這規範同時要處理的尺寸換算規則見 [`08-Remotion算圖管線.md`](08-Remotion算圖管線.md)；什麼時候該用這個風格、什麼時候該用純文字特效，見 [`09-強調字貼紙內容確認規則.md`](09-強調字貼紙內容確認規則.md)。

**核心感覺**：要同時有「懸浮」（漂在畫面上，不是貼死底圖）跟「光芒」（會發光，不是死板陰影卡片），但陰影不能重——太重會蓋掉發光感，變成單純「有厚度的卡片」而不是「發光懸浮的東西」。

## 標準做法：白框＋雙層box-shadow＋緩慢晃動（圖片類內容適用）

不是用CSS `filter: drop-shadow(...)`，是把內容包在**背景全白、圓角的容器**（`FloatCard`元件）裡，用兩層各自獨立的`box-shadow`疊出「框＋光暈＋陰影」三個元素同時存在：

```
boxShadow: [
  `0 ${padding*0.5}px ${padding}px rgba(0,0,0,0.4)`,   // 陰影層：往下偏移、模糊、黑色、透明度0.4（不要更高，會太重）
  `0 0 ${26 + pulse*16}px rgba(255,255,255,${pulse})`,  // 光暈層：置中不偏移、模糊半徑隨pulse呼吸、純白
].join(", ")
```

- 陰影層維持低透明度（0.4是甜蜜點）、往下偏移padding的一半，這是「懸浮在平面上方」的深度線索，不用很重就有效果。
- 光暈層用純白（不要品牌色，非白色會讓亮背景下看起來髒）、置中不偏移、透明度隨時間脈動製造「呼吸發光」感。
- 陣列順序陰影在前、光暈在後（＝CSS層疊順序，光暈疊在陰影上面才不會被蓋掉）。
- 白色容器本身的邊緣就是視覺上的框，不用另外畫border。

**動態參數**（`nativeMotion.ts` / `floatGlow.tsx`）：

- 光暈呼吸：`glowPulse(frame,fps) = 0.75 + 0.15*sin(frame/fps * 2π/1.8)`，1.8秒一週期，振幅0.6–0.9不要太大（太大閃爍感太強不像呼吸）。
- 懸浮晃動：`floatSway(frame,fps,phaseFrames)`回傳`bobY`（`sin(t/fps*2π/2.4)*10`px）跟`rotate`（`sin(t/fps*2π/3.2)*1.6`度）——兩個週期故意不同，晃動才不死板重複；`phaseFrames`讓同畫面多張卡片各自錯開相位，不要同步晃（同步晃像同一個東西被拉線傀儡）。
- 進場用簡單`opacity`＋`scale`（0.9→1）淡入即可，不需要複雜intro動畫。

**替代方案**：如果素材不適合塞進白色卡片（本身是透明PNG小圖示、不需要底板），改用`floatGlow.tsx`的SVG filter版（`GLOW_FILTER`／`GlowDefs`）：對SourceAlpha做`feMorphology`（dilate）分別做出「貼著形狀邊緣的實心白色細框」跟「往外擴散模糊的柔光」兩層再`feMerge`，直接套用在圖片本身的`filter`屬性上，不會生成額外白底卡片，也沒有陰影層。

## 沒有固定外觀比例的內容（特效類，例如爆炸/粒子）：寬高各自撐滿框，不要contain擬合

圖片／Logo有自己的原始比例要保持、不能變形（見 [`08-Remotion算圖管線.md`](08-Remotion算圖管線.md) 的尺寸規則），但**特效本身沒有固定比例可言**——如果用`min(width,height)`去算特效的擴散半徑，會把它硬塞進以較窄邊為準的正方形範圍，浪費掉框的另一個維度（實測案例：172×588的窄長框，特效只用了約172×172的範圍，回饋「太小」）。正確做法：特效的X軸擴散用`width/2`、Y軸擴散用`height/2`各自獨立計算（呈橢圓/矩形擴散貼合框的實際形狀），不要用單一半徑套兩個軸。

## 檔案位置

`remotion-starter/floatGlow.tsx`（SVG filter版）、`remotion-starter/FloatCard.tsx`（白卡版，本規範主要對象）、`remotion-starter/nativeMotion.ts`（`floatSway`／`bouncePop`／`slideEase`三種動態語彙）。新素材要套用這個風格直接`import { FloatCard } from "./FloatCard"`包住內容，不要重寫box-shadow公式。
